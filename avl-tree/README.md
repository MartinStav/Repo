# AVL strom

Samovyvažovací binárny vyhľadávací strom: vloženie, odstránenie, vyhľadanie ID a vyhľadanie intervalu.

## Technológie

C11.

## Spustenie

Príkazy spúšťaj z priečinka `avl-tree/`.

```sh
cmake -S .. -B ../build
cmake --build ../build --target avl_tree
../build/avl_tree < examples/input.txt
```

## Rozsah a obmedzenia

Príkazy: i ID text; s ID [koncové_ID]; d ID. Záznamy v ukážke sú vymyslené.
