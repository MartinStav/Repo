# BALLRUN

Prehliadačová hra: zbieranie bodov, vyhýbanie sa nepriateľom, tri režimy náročnosti, nastavenia a lokálny rebríček.

## Technológie

HTML, CSS, JavaScript, Canvas.

## Spustenie

Príkazy spúšťaj z priečinka `ballrun/`.

```sh
python3 -m http.server 8000
# otvor http://localhost:8000
```
